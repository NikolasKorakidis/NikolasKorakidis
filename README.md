## 🎮 The game I'm building: Echoes of Kharon

<!-- Add a 10–15 s GIF of the ship-to-mech transformation here -->
<!-- <p align="center"><img src="images/echoes-of-kharon.gif" width="720" alt="Echoes of Kharon: ship transforms into a mech"/></p> -->

A 2.5D space shooter that turns into a mech platformer halfway through the run.

| Stage | Mode | Boss |
|---|---|---|
| Orbital Riptide | Horizontal shooter | Choir Engine |
| Foundry Run | Mech action platformer | Forge Regent |

- **Echo Shift:** decode enemy attack patterns into Burst, Arc and Guard modules, then keep them through the transformation
- **Built with** Godot 4 and typed GDScript: component-based design, data-driven tuning, automated headless tests
- **Status:** vertical slice in development, Windows first

➡️ [View the game repo](https://github.com/NikolasKorakidis/mecha-techa-soldier)
